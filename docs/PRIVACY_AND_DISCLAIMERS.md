# Privacy Policy & Legal Disclaimers

Last updated: August 2026

## 1. Zero PII & Local Processing Policy

**heatWave** is built with a zero-data-collection privacy architecture:

- **Zero Data Collection**: heatWave does **not** collect, track, transmit, or store any Personally Identifiable Information (PII), telemetry, usage analytics, device identifiers, or user metrics.
- **100% Local Execution**: All PDF extraction, spatial layout parsing, heat seeding algorithms, timeline estimations, and file rendering occur entirely on the user's local host machine.
- **No Remote Telemetry or Tracking**: The application makes zero background HTTP/HTTPS network requests, calls no external tracking endpoints, and uses no third-party analytics software.

## 3. Rules Compliance & Best-Effort Seeding

- **Convenience Seeding**: Preliminary heat seeding algorithms within heatWave follow published USA Swimming center-out lane placement rules as a automated convenience tool.

Meet directors, referees, and coaches maintain sole responsibility for verifying final meet entries, lane assignments, event seedings, and compliance with official governing body rulebooks before competition.

## 4. Offline Baseline & Future API Scope

- **Offline Desktop Baseline**: heatWave is designed and operated strictly as an offline desktop utility.
- **Future API & Cloud Scope**: Should any future cloud integrations or external API features be developed, they will be strictly **optional, explicit, and opt-in**. Offline desktop functionality will remain fully operational without requiring network access or user accounts.
